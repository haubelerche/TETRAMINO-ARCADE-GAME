# TETRAMINO ARCADE GAME 🎮
made by Thanh Hau Luong with the love for the original legendary game Tetris
## Overview
**TETRAMINO ARCADE GAME** is a classic arcade-style puzzle game built entirely using Java and its standard library. The game challenges players to control falling tetramino blocks, arrange them into complete horizontal lines, and earn points. As the game progresses, the speed of the falling blocks increases, providing a dynamic and engaging experience.

## Features
- **Core Gameplay**: 🎲 Control tetramino shapes to fit them into the grid.
- **Scoring System**: 🏆 Earn points for every line you clear.
- **Level Progression**: 📈 The game increases in difficulty as your score grows.
- **Real-Time Display**: 📊 Track your level, score, and the number of lines cleared.

## Controls
- **W**: 🔄 Change the shape of the current tetramino.
- **A**: ⬅️ Move the tetramino left.
- **D**: ➡️ Move the tetramino right.
- **S**: ⬇️ Speed up the tetramino's descent.

## Requirements
- Java Development Kit (JDK) 8 or higher.

## How to Play
1. 📥 Clone or download the project repository.
2. 🛠️ Compile the project using the `javac` command:
   ```sh
   javac TETRAMINO_ARCADE_GAME.java
   ```
3. ▶️ Run the game using the `java` command:
   ```sh
   java TETRAMINO_ARCADE_GAME
   ```
4. 🎮 Use the controls to manage falling tetramino blocks and clear lines.
5. 🥇 Aim to achieve the highest score possible before the grid fills up!

## Development
The project uses only Java's standard library for simplicity and compatibility. It is an excellent starting point for those looking to learn game development in Java.

### Key Classes and Components
- **GameEngine**: 🧠 Manages the game's logic, including collision detection and level progression.
- **Tetramino**: 🔺 Represents the different tetramino shapes and their rotations.
- **Grid**: 🟦 Handles the game board and line-clearing mechanics.
- **Display**: 🎨 Renders the game and updates the user interface.
